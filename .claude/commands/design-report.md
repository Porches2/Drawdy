# Design report

You are drafting a design-update status report for me to review before I post it. Follow these steps in order. **Never post anything to Slack yourself** — your only job is to hand me a finished draft that I read, edit, and send myself.

## 1. Read the design board

- Use the Claude Design connector (List artifacts / Read artifact) to open the **XOXONA** design board.
- If the board is NOT reachable from this session, STOP and tell me plainly: "I can't see the XOXONA design board from here — run this where the Claude Design connector is connected, or paste the recent frame changes and I'll format them." Do not invent or guess design details.

## 2. Work out what is actually new

- Read the recent posts in the **#xoxona-designer** Slack channel to find my most recent design update(s).
- Compare the board against what I have already reported. Only include things that are genuinely new or changed since my last update — do not repeat anything already covered.
- Group related changes under the feature/area they belong to (e.g. Gift Stage Backdrops, Mascot Lab, Profile photo crop, Prism history in Settings).

## 3. Draft the report — neat, friendly, easy to read

Write it so a teammate can skim it in about 15 seconds and know exactly what changed and where to look. Keep my voice, but make it clean and scannable:

- Open with a short, friendly one-line intro of what this update covers.
- For each area: a bold header, a short "where to find it" line (which page/screen in the file), then 1–3 short, plain-language bullets on what changed. No walls of jargon.
- Keep bullets concrete ("new backdrop set per gift tier"), not vague ("updated styling").
- End with a short, friendly sign-off line.

Use this shape (adapt the wording so it sounds like me, not robotic):

```
*Design update — a few things I've been on* 👇
@[tag the usual people]

Quick rundown of what's changed on the design file 👇
[artifact link]

*✨ [Area name]*
_Where:_ `[page / screen]`
• [what changed]
• [anything added]

*✨ [Area name]*
_Where:_ `[page / screen]`
• [what changed]
```

## 4. Hand it to me

- Show the full draft here in the chat.
- If I ask you to put it in Slack, create it as a **draft** in #xoxona-designer (or wherever I say) so that I press send myself — never send it directly to the channel.
- Flag anything you were unsure about so I can double-check it before it goes out.
