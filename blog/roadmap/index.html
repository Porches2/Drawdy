Our Roadmap: What's Coming Next

May 28, 2026 · Alex Kim · 2 min read

We believe in building in the open. Here’s what we’re working on and what’s coming next.

Now: Foundation

These are shipping in the next few weeks:

  • Real-time collaboration. Live cursors, presence indicators, and conflict-free editing with the people you invite.
  • Export improvements. PNG, SVG, and PDF export with both hand-drawn and clean rendering modes.
  • Keyboard shortcuts overhaul. A comprehensive shortcut system with a command palette for power users.
  • Performance optimizations. We’re targeting 60fps on boards with 1,000+ elements. Current benchmarks are promising.

Next: Platform

These are in active development:

  • Plugin API v1. The developer-facing API for building custom node types, canvas actions, and integrations. We’re working with early partners to refine the API before release.
  • Plugin registry. A place to discover and install community-built plugins. Think of it as a curated marketplace for canvas extensions.
  • Template library. Pre-built board templates for common use cases: architecture diagrams, user story maps, sprint retrospectives, system design interviews.
  • Board linking. Connect boards to each other. Navigate between related diagrams like pages in a wiki.

Later: Ecosystem

These are on the horizon:

  • Mobile app. View and lightly edit boards on iOS and Android. Heavy editing stays on desktop where you have screen real estate.
  • API access. Programmatic access to read and write board data. Build automations, generate boards from code, integrate with CI/CD pipelines.
  • Team workspaces. Shared spaces for teams with role-based access, shared templates, and centralized billing.
  • AI assistance. Smart layout suggestions, diagram generation from text descriptions, and automated documentation from board content.

What we won’t build

Transparency goes both ways. Here’s what we’re intentionally not building:

  • Slide presentations. Drawdy is a canvas for thinking, not a slide deck tool. There are great tools for presentations already.
  • Project management. We’re not building Gantt charts, sprint boards, or time tracking. We’ll integrate with tools that do this well.
  • A design tool. Drawdy is for architecture and systems thinking. If you need pixel-perfect UI design, use Figma.

Your input matters

This roadmap isn’t set in stone. We prioritize based on what users actually need, not what sounds impressive on a features page.

If there’s something you’d love to see, let us know. The best product decisions come from real conversations with the people using the tool.
